================================================================================
               ІНСТРУКЦІЯ З ВИКОРИСТАННЯ ZOOM VIDEO AUTOMATION
================================================================================

Цей посібник допоможе вам налаштувати та використовувати програму для автоматичного
пошуку записів Zoom, завантаження їх на YouTube та синхронізації з уроками у SendPulse LMS.


--------------------------------------------------------------------------------
1. СТРУКТУРА ПАПОК (ЩО МАЄ БУТИ ПОРУЧ ІЗ ПРОГРАМОЮ)
--------------------------------------------------------------------------------

Для повноцінної роботи програми (як у вигляді .exe на Windows, так і .app на macOS,
або при запуску через скрипти) поруч із виконуваним файлом мають знаходитися такі папки:

Ваша_Папка_Програми/
│
├── ZoomAutomation_GUI.app  (на macOS) АБО  ZoomUploader.exe  (на Windows)
│   (або скрипти запуску: run.sh / Run.bat)
│
├── configs/                [ОБОВ'ЯЗКОВО] Папка з налаштуваннями
│   ├── client_secret.json  -> Ключ авторизації Google OAuth (YouTube API)
│   ├── config.json         -> Головні налаштування (шлях Zoom, токени)
│   ├── schedule.json       -> Розклад занять
│   └── token.json          -> Генерується автоматично після першого входу в YouTube
│
├── thumbnails/             [ОПЦІОНАЛЬНО] Обкладинки для відео
│   └── (картинки .jpg або .png, які автоматично ставляться як прев'ю на YouTube)
│
├── assets/                 [СИСТЕМНО] Іконки та оформлення інтерфейсу
│
└── reports/                [АВТОМАТИЧНО] Звіти про завантаження
    └── (сюди зберігаються детальні CSV та TXT звіти про кожен запуск)


--------------------------------------------------------------------------------
2. НАЛАШТУВАННЯ КАЛЕНДАРЯ ТА РОЗКЛАДУ ЗАНЯТЬ
--------------------------------------------------------------------------------

Програма визначає, до якого курсу належить запис Zoom, зіставляючи ДЕНЬ ТИЖНЯ та ЧАС
створення папки запису з вашим розкладом.

2.1. НАЛАШТУВАННЯ ЧЕРЕЗ ГРАФІЧНИЙ ІНТЕРФЕЙС (UI):
-------------------------------------------------
1. Відкрийте програму та перейдіть на вкладку «Weekly Schedule» (Тижневий розклад).
2. Натисніть кнопку «+ Add Lesson» (або клікніть на порожню клітинку потрібної години).
3. Заповніть поля:
   - Day: день тижня (Monday - Sunday).
   - Time: час початку уроку (наприклад, 18:00).
   - Course Name: назва курсу (наприклад: «Unity Basic» або «Python Pro»).
   - LMS Course ID: числовий ID курсу в SendPulse (наприклад: 35014).
   - Thumbnail: назва файлу обкладинки з папки thumbnails/ (наприклад: unity.jpg).
   - Duration: тривалість уроку у хвилинах (за замовчуванням 60).
   - Color: колір картки в календарі (для зручності).
4. Натисніть «Save». Зміни збережуться автоматично.

2.2. НАЛАШТУВАННЯ ЧЕРЕЗ ФАЙЛ configs/schedule.json:
--------------------------------------------------
Файл можна редагувати у будь-якому текстовому редакторі (Блокнот, VS Code).
Дні тижня мають бути вказані АНГЛІЙСЬКОЮ мовою з великої літери:
"Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", "Sunday".

Приклад структури configs/schedule.json:
{
  "Monday": {
    "18:00": {
      "name": "Python Basic",
      "lms_course_id": "8922086",
      "thumbnail": "python.jpg",
      "duration": 60,
      "color": "#3b8ed0"
    }
  },
  "Saturday": {
    "11:00": {
      "name": "Web Design",
      "lms_course_id": "7654321",
      "thumbnail": "web.png",
      "duration": 90
    }
  }
}

2.3. ЯК МАЄ ЗВУЧАТИ НАЗВА УРОКУ:
--------------------------------
* На YouTube назва формується автоматично у форматі:
  «Назва Курсу/ДД.ММ.РРРР»  -> Наприклад: «Python Basic/10.04.2026»
  Якщо запис складався з декількох частин, додається маркер частини:
  «Python Basic/10.04.2026 Ч1», «Python Basic/10.04.2026 Ч2».

* У SendPulse LMS (ВАЖЛИВО!):
  Щоб програма знайшла потрібний урок у курсі LMS і прикріпила відео, назва уроку
  в кабінеті SendPulse ОБОВ'ЯЗКОВО повинна містити дату уроку у форматі ДД.ММ.РР
  (день.місяць.двозначний_рік).
  Приклади правильних назв уроку в LMS:
  - «Урок 5 (10.04.26)»           -> ЗНАЙДЕ
  - «10.04.26 - Основи циклів»     -> ЗНАЙДЕ
  - «Заняття від 10.04.26»         -> ЗНАЙДЕ
  - «Основи Python» (без дати)     -> НЕ знайде (програма пропустить)


--------------------------------------------------------------------------------
3. ЯК ОТРИМАТИ ТОКЕН ДЛЯ SENDPULSE LMS
--------------------------------------------------------------------------------

Для оновлення уроків у SendPulse потрібен Bearer-токен авторизації.

Найшвидший спосіб отримати діючий токен (через браузер):
1. Відкрийте браузер (Google Chrome, Edge або Safari) і увійдіть у свій акаунт SendPulse.
2. Перейдіть у розділ «Курси» (EDU / LMS).
3. Натисніть клавішу F12 (або правий клік миші -> «Переглянути код» / «Inspect»).
4. У панелі розробника, що відкриється, перейдіть на вкладку «Network» (Мережа).
5. Оновіть сторінку в браузері (F5 або Ctrl+R / Cmd+R).
6. У списку запитів знайдіть будь-який запит, де у стовпчику Name є слово `courses`, `lessons` або `user`.
7. Клікніть на цей запит, праворуч відкрийте вкладку «Headers» (Заголовки) і знайдіть блок «Request Headers» (Заголовки запиту).
8. Знайдіть рядок `Authorization: Bearer eyJ...`.
9. Скопіюйте довгий текст ПІСЛЯ слова «Bearer » (без самого слова «Bearer»).
10. Вставте цей токен у програмі: вкладка «General Settings» -> поле «LMS API Token» -> натисніть «Save All Settings».

(Токен зберігається у файлі configs/config.json у полі "LMS_TOKEN").


--------------------------------------------------------------------------------
4. ДЕ ДІЗНАТИСЬ ID ШКОЛИ ТА ID КУРСУ
--------------------------------------------------------------------------------

4.1. ДЕ ЗНАЙТИ ID ШКОЛИ (SCHOOL ID):
- В кабінеті SendPulse перейдіть у налаштування вашої онлайн-школи або подивіться на адресу в браузері при вході в кабінет курсів.
- Також його видно у тому ж мережевому запиті (Network), наприклад у посиланні:
  `.../api/v1/courses/18828/...` -> число `18828` і є ваш SCHOOL_ID.
- Вкажіть його у програмі в «General Settings» -> «LMS School ID».

4.2. ДЕ ЗНАЙТИ ID КУРСУ (LMS COURSE ID):
1. У кабінеті SendPulse відкрийте потрібний курс (наприклад, для редагування).
2. Подивіться на адресний рядок браузера:
   `https://login.sendpulse.com/edu-service/courses/8922086/lessons`
   Числове значення (в даному прикладі `8922086`) — це і є унікальний ID курсу.
3. Вкажіть цей числовий ID у розкладі для відповідного заняття (поле «LMS Course ID»).


--------------------------------------------------------------------------------
5. РОБОТА З ДОДАТКОМ, ЛОГИ ТА СТАТУСИ ЗАВАНТАЖЕННЯ
--------------------------------------------------------------------------------

5.1. РЕЖИМИ РОБОТИ (вкладка Dashboard):
- «Full Auto» (Режим 1): Повний цикл. Знаходить нові записи Zoom -> Завантажує на YouTube -> Додає до плейлиста -> Синхронізує кнопку з LMS -> Переносить папку Zoom у Кошик.
- «YT Only» (Режим 2): Тільки завантаження на YouTube та додавання в плейлист (без оновлення сайту LMS).
- «LMS Only» (Режим 3): Тільки оновлення сайту LMS на основі раніше згенерованого YouTube CSV-звіту.

5.2. ЛОГИ В ІНТЕРФЕЙСІ (поле «Console Log»):
Під час роботи в полі логів відображається кожен крок:
- `Found X video folders to process` — скільки нових папок знайдено в Zoom.
- `Matched Course: Python Basic` — курс успішно знайдено у вашому розкладі.
- `Uploading... 45%` — прогрес вивантаження файлу на YouTube.
- `Upload Complete: https://youtu.be/...` — посилання на створене відео.
- `Thumbnail updated` — обкладинка успішно встановлена.
- `Modifying content for lesson...` — пошук кнопки «Відео» в уроці SendPulse.
- `PUT ... | 200` — урок у SendPulse успішно оновлено.

5.3. СТАТУСИ У ЗВІТАХ ТА ЇХ ЗНАЧЕННЯ:
Після кожного запуску створюється звіт у папці `reports/` (його можна переглянути прямо в програмі через вкладку «Reports History» або кнопку «Latest Report»):

* **SUCCESS** (Зелений):
  Відео успішно завантажено на YouTube, додано до плейлиста, а посилання вставлено в урок LMS. Папка в Zoom переміщена в Кошик.

* **ALREADY_UPLOADED** (Синій):
  У папці з відео знайдено файл-маркер `.uploaded_to_youtube`. Це означає, що відео вже було завантажене раніше. Програма не завантажує дублікати повторно.

* **SKIPPED** (Жовтий/Помаранчевий):
  Відео пропущено. Причини в стовпчику Details:
  - «Not in schedule»: час створення відео не відповідає жодному уроку в календарі.
  - «no lms meta»: для курсу не вказано LMS Course ID.
  - «lesson not found»: в курсі LMS не знайдено уроку з відповідною датою (ДД.ММ.РР).

* **FAIL / ERROR** (Червоний):
  Виникла помилка. У стовпчику Details буде точний текст:
  - Помилка авторизації YouTube (потрібно перевірити client_secret.json).
  - Помилка токена LMS (LMS_AUTH_ERROR: оновіть токен у налаштуваннях).
  - Відсутність інтернету або ліміт квоти YouTube API.


--------------------------------------------------------------------------------
6. ПЛАНУВАЛЬНИК АВТОМАТИЗАЦІЇ (Automation Planner)
--------------------------------------------------------------------------------

Якщо увімкнути перемикач на вкладці «Automation Planner»:
- Програма може автоматично запускати обробку щогодини (Hourly), щодня в заданий час (Daily) або щотижня (Weekly).
- Галочка «Require confirmation»: якщо увімкнена, програма перед стартом запитає вас діалоговим вікном «Запустити автоматизацію?». Якщо вимкнена — запустить фоново без зайвих питань.
- На Windows при закритті на хрестик [X] програма продовжує працювати у системному треї (біля годинника), щоб виконувати завдання за розкладом.
